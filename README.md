# Task Management Android App

This is an Android application to manage tasks.

## Features

*   **Firebase Integration:** Tasks are stored and synced with Google Firebase.
*   **Multiple Views:** View tasks in Day, Week, or Month format.
*   **Task Properties:** Each task includes:
    *   Title
    *   Description
    *   Start Time
    *   End Time
    *   Status (To Do, In Progress, Complete)
